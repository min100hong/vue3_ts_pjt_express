# frontend

This template should help get you started developing with Vue 3 in Vite.
- .env.development : 개발환경
- .env.production  : 운영환경
  
- npm install dotenv

- compileOption 설정 : tsconfig.json  

- proxy 설정
  - vite.config.ts 파일에서 설정

- cd frontend
- npm run start
